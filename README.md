# 🛒 Big Mart Sales Prediction

This project predicts the sales of products at different Big Mart outlets using machine learning techniques.  
It involves **data cleaning, feature engineering, exploratory data analysis (EDA), and model training** to build a predictive model.

---

## 📊 Dataset
The dataset contains sales data for various products across multiple stores.  
Key features include:
- Item details (weight, visibility, type, MRP)
- Outlet details (size, location, type)
- Sales values (target variable)

---

## 🛠️ Project Workflow
1. **Data Preprocessing**
   - Handling missing values
   - Encoding categorical variables
   - Outlier detection & treatment
   - Feature scaling & transformation

2. **Exploratory Data Analysis (EDA)**
   - Visualizing sales distribution
   - Correlation analysis
   - Product & outlet trends

3. **Model Building**
   - Train-test split
   - Algorithms: Linear Regression, Random Forest, XGBoost
   - Performance evaluation using RMSE & R² Score

4. **Results**
   - Best performing model identified
   - Predictions generated for unseen data
